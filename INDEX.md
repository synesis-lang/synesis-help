## Field types

*What each TYPE accepts.*

| Entry | Description |
|---|---|
| [**QUOTATION**](TYPE_QUOTATION) | Literal excerpt transcribed from the source: the evidence. |
| [**CODE**](TYPE_CODE) | One or more concepts of the ontology assigned to the unit. |
| [**MEMO**](TYPE_MEMO) | Free note by the researcher: interpretation, justification. |
| [**TEXT**](TYPE_TEXT) | Short text: a description, a context value, an identifier. |
| [**CHAIN**](TYPE_CHAIN) | Concepts linked by declared relations: a claim about the world. |
| [**TOPIC**](TYPE_TOPIC) | A single term, without spaces, that groups concepts. |
| [**ENUMERATED**](TYPE_ENUMERATED) | One value from a closed list, without order. |
| [**ORDERED**](TYPE_ORDERED) | One value from a closed list, with order; written as its index. |
| [**SCALE**](TYPE_SCALE) | Number inside a declared interval (intensity, confidence). |
| [**DATE**](TYPE_DATE) | A date. |
